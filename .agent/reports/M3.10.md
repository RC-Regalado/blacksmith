# Milestone M3.10 Report - Implement `run_tests`

Date: 2026-08-04

## Status

implemented-awaiting-human-review

## Summary

Implemented Python-side `run_tests` for approved fixed test profiles.

The tool accepts only:

- workspace-confined `path`;
- approved `profile_id`;
- optional stdout/stderr byte caps.

The model cannot provide argv, shell fragments, environment variables,
executables, package-install commands or arbitrary profile definitions.

## Security review

- No shell execution was introduced.
- Model-supplied argv, executable, environment and package-install commands are rejected.
- Process environment is explicit and does not inherit arbitrary secret variables.
- Output is redacted and bounded before returning.
- `EXECUTE_PROJECT` requires confirmation before execution.
