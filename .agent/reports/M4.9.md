## Changes

- Expanded `ExecutionStore` port to persist objectives, plans, executions, task states and checkpoints.
- Added `ExecutionStoreError`.
- Added `SQLiteExecutionStore` in `ai_assistant/infrastructure/storage/sqlite_execution.py`.
- Added dedicated execution tables:
  - `execution_objectives`
  - `execution_plans`
  - `execution_tasks`
  - `executions`
  - `execution_checkpoints`
- Added tests for restart reload, task status persistence, checkpoint persistence, dedicated tables and transactional rollback on failed plan replacement.
- Recorded M4.8 approval and queued M4.9 for manual review.
