# M4.12 Report — Structured Planner Adapter

## Status

implemented-awaiting-human-review

## Scope

Added a model-backed planner adapter over the existing `ModelProvider` port. No Ollama-specific code, scheduling, execution or persistence behavior was added.

## Changes

- Added `ModelBackedPlanner`.
- Sends objective and planner-facing capability metadata to `ModelProvider`.
- Requires strict JSON with `plan_id` and `tasks`.
- Maps structured model output to provider-neutral `Plan` and `PlatformTask`.
- Rejects invalid JSON, malformed task fields and unknown capabilities before scheduling.
- Added focused tests in `tests/test_platform_structured_planner.py`.
- Recorded M4.11 approval and queued M4.12 for manual review.
