## Status

implemented-awaiting-human-review

## Summary

M5.7 adds deterministic text normalization and bounded chunk generation for derived knowledge.

Implemented:

- `ChunkingConfig`.
- `normalize_text()`.
- `chunk_document()`.
- Markdown heading-aware chunks.
- Python top-level `class`/`def` chunk units using stdlib `ast`.
- Bounded fallback chunks for other text.

Not implemented in this milestone:

- Source adapters.
- Persisted symbol extraction.
- Metadata enrichment beyond chunk section labels.
- FTS5, embeddings, retrieval, ranking or context compilation.
