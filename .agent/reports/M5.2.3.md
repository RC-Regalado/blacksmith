# M5.2.3 — Implement Provider-Neutral ModelResponse

(Covers M5.2.3, M5.2.4 and M5.2.5 together — implemented in one coherent change set since they share the same files: `ai_assistant/domain/model_response.py`, `ai_assistant/application/ports/models.py`, `ai_assistant/infrastructure/models/*`, `ai_assistant/bootstrap/config.py`, `ai_assistant/bootstrap/container.py`. M5.2.4 and M5.2.5 have their own short reports pointing back here.)

## Status

automatically-accepted

## Scope

- M5.2.3: `ModelProvider.chat()` returns a provider-neutral `ModelResponse` (ADR-068) across `dummy`, `ollama`, `openai_compatible` and the `ModelAdapter` facade.
- M5.2.4: Ollama adapter captures `done`, `done_reason`, `prompt_eval_count`, `eval_count` and maps them onto `ModelResponse.finish_reason`/`truncated`/`prompt_tokens`/`output_tokens` (remediates FINDING-002).
- M5.2.5: Ollama adapter accepts explicit `num_ctx`/`num_predict`, sends them only when configured, and surfaces the configured values in `ModelResponse.metadata` plus a log line (remediates the Ollama half of FINDING-008).

## Implementation evidence

- New `ai_assistant/domain/model_response.py`: frozen `ModelResponse` (message, finish_reason, prompt_tokens, output_tokens, duration_ms, truncated, metadata) and `FinishReason` StrEnum (STOP/LENGTH/TOOL_CALL/ERROR/UNKNOWN).
- `ai_assistant/application/ports/models.py`: `ModelProvider.chat(messages) -> ModelResponse`.
- `ai_assistant/infrastructure/models/dummy.py`: wraps its deterministic `Message` in `ModelResponse(finish_reason=FinishReason.STOP)`, no tokens/randomness added.
- `ai_assistant/infrastructure/models/ollama.py`: reads `done_reason`/`prompt_eval_count`/`eval_count`; `_build_payload` adds `options.num_ctx`/`options.num_predict` only when the provider instance carries non-`None` values.
- `ai_assistant/infrastructure/models/openai_compatible.py`: best-effort `status`/`incomplete_details`/`usage` mapping onto the same neutral contract.
- `ai_assistant/bootstrap/config.py` / `container.py`: `AI_ASSISTANT_OLLAMA_NUM_CTX` / `AI_ASSISTANT_OLLAMA_NUM_PREDICT` wired through to the provider.
- `ai_assistant/application/runtime.py`, `ai_assistant/platform/application/planner.py`: unwrap `.message` at the two real call sites only; no tool-loop control-flow change. `AgentRuntime.respond()` still returns a plain `Message`.
