implemented-awaiting-human-review

## Summary

M5.10 adds explicit manual CLI commands for derived knowledge indexing and lexical query.

Implemented:

- `AI_ASSISTANT_KNOWLEDGE_DATABASE`.
- `python main.py knowledge status`.
- `python main.py knowledge index PATH`.
- `python main.py knowledge rebuild PATH`.
- `python main.py knowledge query TEXT`.
- Workspace-relative path confinement.
- Hidden/sensitive path denial.
- Max file byte limit enforcement.
- Skip unchanged fresh files by version/hash.

Not implemented in this milestone:

- Background watcher.
- Automatic runtime retrieval.
- Embeddings.
- Hybrid retrieval or ranking.
- Context compilation.
