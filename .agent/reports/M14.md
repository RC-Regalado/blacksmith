## Tool format

Phase 1 recognizes one explicit JSON object in an assistant message:

```json
{
  "tool_call": {
    "id": "call-1",
    "name": "search",
    "arguments": {"q": "example"}
  }
}
```

Plain assistant text is ignored. Invalid explicit `tool_call` structures raise `InvalidToolCallError`.
