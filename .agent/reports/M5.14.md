## Summary

M5.14 adds deterministic, inspectable ranking for retrieval candidates.

Implemented:

- `RankedCandidate`.
- `KnowledgeRanker`.
- Component scores for base candidate score and retrieval method.
- Fixed method weights for `symbol`, `fts5` and `semantic`.
- Stable tie-breaking by source URI and chunk ID.
- Stale candidate exclusion.

Not implemented in this milestone:

- LLM reranker.
- ContextCompiler.
- Planner/synthesis/runtime integration.
