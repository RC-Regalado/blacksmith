## Policy

- Budget uses approximate character count of message content.
- System prompt and current user input are always included.
- History is considered from newest to oldest.
- Selection stops when the next recent message does not fit.
- Selected history is sent in original chronological order.

## Architecture review

- ADR-007 respected: budget is configured at bootstrap.
- ADR-015 respected: context limit remains configurable.
- No tokenizer, summarization, embeddings or semantic memory was added.
