## Summary

M5.12 adds local embedding persistence and bounded CPU semantic similarity search.

Implemented:

- `knowledge_embeddings` SQLite table.
- `KnowledgeStore.save_embedding()`.
- `KnowledgeStore.embeddings_for_chunk()`.
- `KnowledgeStore.semantic_search()`.
- Provider/model/version/dimension compatibility checks.
- Freshness filtering for semantic candidates.
- Cosine similarity implemented with stdlib only.

Not implemented in this milestone:

- HybridRetriever.
- Deterministic ranker.
- Context compilation.
- Runtime integration.
- External vector database.
