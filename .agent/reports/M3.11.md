# Milestone M3.11 Report - Implement `build_project`

Date: 2026-08-04

## Status

implemented-awaiting-human-review

## Summary

Implemented Python-side `build_project` using the same fixed-profile process path
as `run_tests`.

The default approved build profile is:

```text
python-compile -> ["python", "-m", "compileall", "-q", "ai_assistant", "main.py"]
```

The model cannot provide argv, shell fragments, environment variables,
executables, package-install commands or arbitrary profile definitions.

## Security review

- No shell execution was introduced.
- Model-supplied argv, executable, environment and package-install commands are rejected.
- Build profile environment is explicit and sanitized.
- Output is redacted and bounded before returning.
- `EXECUTE_PROJECT` confirmation remains required before execution.

## Residual risks

- Runtime CLI prompt integration for confirmation remains later scope.
- C toolserver does not implement `build_project` yet; M3.14 remains the milestone for making the C toolserver primary.
- Approved build profiles still execute project-local code and must remain reviewed before expansion.
