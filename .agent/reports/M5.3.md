## Acceptance evidence
- `ai_assistant/knowledge/domain.py` defines `KnowledgeDocument`, `KnowledgeChunk`, `KnowledgeSymbol`, `KnowledgeQuery`, `RetrievalCandidate`, `ContextEvidence`, `CompiledContext` and `ContextBudget`.
- `ContextEvidence` rejects stale or unknown knowledge by requiring `FreshnessStatus.FRESH`.
- `CompiledContext` enforces `ContextBudget` limits for total tokens, sources, chunks and per-chunk tokens.
- Domain models are immutable dataclasses and have no infrastructure dependencies.

## Architecture review
- KnowledgeStore remains unimplemented and therefore separate from canonical stores.
- Domain models depend only on stdlib and domain errors.
- EmbeddingProvider and ModelProvider remain untouched and separate.
- No new production dependency was added.

## Freshness review
- `FreshnessStatus` supports fresh, stale and unknown.
- `ContextEvidence` only accepts fresh candidates.
- `CompiledContext` can only contain evidence already validated as fresh.

## Security review
- No indexing of audit, sensitive files or conversations was implemented.
- No network retrieval, watcher daemon, MCP, external vector DB, semantic long-term memory or automatic skill behavior was added.
