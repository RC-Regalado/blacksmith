## Architecture review

- Applicable ADRs: ADR-026, ADR-027, ADR-028, ADR-023.
- Conformance: `file_metadata` is statically allowlisted, uses `READ_METADATA`, does not return content and has validation in Python and C.
- Deviations: Runtime permission assignment is not changed in M3.6; later integration must assign catalog permissions rather than trusting model output.

## Security and safety review

- Findings: No content is read into the metadata response. Hidden/sensitive path denial and symlink escape denial are reused.
- Residual risks: Full productive default via C waits for M3.14; runtime integration waits for M3.16.
