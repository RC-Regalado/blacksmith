# Milestone M3.9 Report - Implement `git_diff`

Date: 2026-08-04

## Status

implemented-awaiting-human-review

## Summary

Implemented Python-side `git_diff` for the local tool executor.

The tool uses fixed Git invocations:

- `git rev-parse --show-toplevel` to locate the repository root;
- `git diff --name-only -z` with optional `--cached` to enumerate changed files;
- `git diff --no-ext-diff --no-color` with optional `--cached` for the bounded diff.

No shell, model-controlled Git subcommand, model-controlled flags, arbitrary
revision, pager, hooks or external diff tool were added.

## Security review

- No shell execution was introduced.
- No arbitrary Git subcommands, revisions, flags or environment are accepted from the model.
- Repository root must remain inside the configured workspace.
- Hidden and sensitive path components are omitted from diff paths.
- Sensitive-looking diff content is redacted before returning.

## Residual risks

- Runtime permission assignment for new Phase 3 tools is still later integration scope.
- C toolserver does not implement `git_diff` yet; M3.14 remains the milestone for making the C toolserver primary.
- Redaction is heuristic; path filtering remains the main protection for known sensitive files.
