## Combined changes

- Added `append_many(session_id, messages)` to `ConversationMemory`.
- Made `InMemoryConversationStore.append()` delegate to `append_many()`.
- Made `SQLiteConversationStore.append_many()` insert all messages inside one SQLite connection transaction.
- Updated `AgentRuntime._persist_turn()` to persist user and assistant messages in one store call.
- Added SQLite role `CHECK` constraint for new databases, used by rollback coverage.
- Added tests for in-memory all-or-nothing behavior, runtime store failure, and SQLite rollback.
