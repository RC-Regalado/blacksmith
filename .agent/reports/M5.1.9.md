# M5.1.9 — Knowledge Status UX

## Status

automatically-accepted

## Summary

Implemented explicit knowledge lifecycle diagnostics in the existing CLI. `knowledge status` now reports `empty`, `fresh`, `partially-stale`, `stale` or `error`; `knowledge query` now explains empty, stale-only and fresh no-match states without rebuilding.

## Implementation Evidence

- `KnowledgeCli._status()` computes lifecycle state from existing `KnowledgeStore.list_documents()` freshness data.
- `KnowledgeCli._query()` prints diagnostics when fresh lexical search returns no candidates.
- `docs/knowledge-engine.md` documents lifecycle labels and explicit manual rebuild/index guidance.
- No store API, dependency, watcher or automatic rebuild behavior was added.
