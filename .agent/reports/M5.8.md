implemented-awaiting-human-review

## Summary

M5.8 adds derived provenance metadata and symbol extraction for knowledge chunks.

Implemented:

- `document_metadata()`.
- `infer_language()`.
- Chunk metadata for source URI, source type, version, document hash and language.
- Chunk metadata for Python and Markdown symbol names/kinds.
- `symbols_for_chunks()` for derived `KnowledgeSymbol` records.

Not implemented in this milestone:

- Source adapters.
- FTS5 indexing.
- Embeddings, retrieval, ranking or context compilation.
