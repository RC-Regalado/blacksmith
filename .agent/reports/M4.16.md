## Combined changes

- `ExecutionEngine` logs objective ID, plan ID, task count, execution status, budget counters, task execution metadata and final evaluation status.
- `TaskScheduler` logs task status transitions.
- `CheckpointService` logs checkpoint metadata IDs only.
- Logs do not include objective descriptions, planner prompts, tool arguments, tool outputs or file content.
