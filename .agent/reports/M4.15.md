## Combined changes

- `CliApplication.run()` accepts optional argv.
- No-argument CLI behavior remains the existing chat loop.
- `objective` command creates an `Objective`, runs the Phase 4 `ExecutionEngine`, and displays objective ID, execution status, evaluation status, budget use, plan tasks, evidence and error code.
- Added `AI_ASSISTANT_EXECUTION_DATABASE` so ExecutionStore stays separate from ConversationStore and AuditStore.
- README documents the new execution database variable and objective command.
