## Error mappings

- Invalid config and log level -> `ConfigurationError`.
- Invalid message -> `InvalidMessageError`.
- Invalid session -> `InvalidSessionError`.
- SQLite failures -> `ConversationStoreError`.
- OpenAI-compatible 404 -> `ModelNotFoundError`.
- OpenAI-compatible timeout -> `ModelTimeoutError`.
- OpenAI-compatible connection failure -> `ModelConnectionError`.
- OpenAI-compatible invalid JSON or missing assistant text -> `ModelProtocolError`.
