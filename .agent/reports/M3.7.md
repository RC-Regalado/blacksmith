# Milestone M3.7 Report - Implement `search_text`

Date: 2026-08-03

## Status

implemented-awaiting-human-review

## Summary

Implemented Python-side `search_text` for the local tool executor.

The tool uses fixed `rg` (`ripgrep`) invocations:

- `rg --files` to enumerate bounded candidate files;
- `rg --json --fixed-strings` to search literal text over the bounded file list.

No shell, model-controlled executable, model-controlled flags or `grep` fallback were added.

## Security review

- No shell execution was introduced.
- No arbitrary argv, flags, executable or environment are accepted from the model.
- No `grep` fallback was introduced.
- Missing `rg` returns typed sanitized error `search_backend_unavailable`.
- Preview redaction is heuristic and does not replace path denial.

## Residual risks

- Runtime permission assignment for new Phase 3 tools is still later integration scope.
- C toolserver does not implement `search_text` yet; M3.14 remains the milestone for making the C toolserver primary.
- Redaction cannot guarantee all secrets are caught; hidden and sensitive path exclusion remain the main control.
