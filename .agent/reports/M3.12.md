# M3.12 Report — Implement Write Policy

## Status

implemented-awaiting-human-review

## Scope

- Added declarative `write` catalog metadata with `WRITE_WORKSPACE` permission.
- Added deny-by-default validation for `create` and `replace` modes only.
- Added bounded UTF-8 text content policy and optional lowercase SHA-256 precondition shape validation.
- Added workspace path validation for create and replace targets.
- Kept actual file mutation out of scope for M3.13.

## Acceptance Evidence

- Only create/replace: covered by `tests/test_tool_policy.py`.
- Workspace-confined: covered by `tests/test_path_policy.py`.
- Hidden, sensitive, external symlink and oversized writes denied: covered by `tests/test_path_policy.py` and `tests/test_tool_policy.py`.
- Denied writes never reach executor: covered by `tests/test_tool_coordinator.py`.
