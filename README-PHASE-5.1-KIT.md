# Phase 5.1 Codex Kit

## Purpose

Integrate chat, Knowledge Engine, tools, metrics and CLI into one coherent operator experience.

## Special execution model

This mini-phase does not require human review after every milestone.

Codex must:

1. implement milestone;
2. validate with subagents;
3. run architecture/security checks;
4. create corrective tasks if needed;
5. repeat until milestone passes;
6. mark milestone automatically-accepted;
7. continue.

One human review occurs only after all Phase 5.1 milestones pass.

## Install

Merge this kit into the repository.

Preserve:

- previous ADR history;
- previous `.agent` reports;
- previous human-review entries.

Merge the Phase 5.1 ADR index into the canonical ADR index.

Use `SUPERVISOR-INITIAL-PROMPT-PHASE-5.1.md` to begin.
